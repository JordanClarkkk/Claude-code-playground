# Design System Documentation

## Reference Files

Design system documentation for styling and components:

- `universe-components.md` - Web Components documentation (v-button, v-icon, v-tag, etc.)
- `ember-components.md` - Ember/Glimmer components (VModal, VSelect, VChip, VDatepicker, etc.)
- `css-vars.md` - all CSS variables (colors, spacing, borders)
- `mixins.md` - all SCSS mixins (typography, accessibility, animation, scrollbar)
- `icons.md` - all icon names with descriptions
